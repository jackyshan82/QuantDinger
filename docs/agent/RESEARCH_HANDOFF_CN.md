# 本地策略研究交接

租户相关的运行记录、账户信息和研究结果保存在本地，不随公共代码提交。继续研究前，先查阅本机已有记录并通过 Agent Gateway 核验当前状态，不能直接复用历史 ID 或收益结论。

本工作区在同步远程代码前的完整中文交接已原样归档到 `artifacts/local-research/RESEARCH_HANDOFF_CN_before_sync_20261122.md`；英文记录位于同目录。若新检出目录没有这些本地文件，应从已授权的当前记录重新建立研究上下文，不推断租户、持仓或实盘授权。

研究流程见 [研究技能](../../.agents/skills/quantdinger-research/SKILL.md)，连接与权限见 [Agent 快速开始](AGENT_QUICKSTART_CN.md)。本索引不授予下单或部署权限。
